# Tree Planting Website

A responsive multi-page Tree Planting website.

## Pages
- Home
- About
- Events
- Partnership

## Home slideshow
The main image section on the Home page is an automatic slideshow.
- Changes every 4 seconds
- Smooth fade transition
- Slight zoom animation
- Navigation dots
- Pauses on hover/focus
- Automatically loops

## Run
Open `index.html` in a modern browser.

The website currently uses remote Unsplash images. Internet access is required for those images to load.
